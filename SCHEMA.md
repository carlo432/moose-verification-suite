# SCHEMA.md — the case contract

Fixed layout and fixed field names. `run_all.py` and the report generator read these files. A
renamed field silently drops a row from the results table and you will not notice for a week.

---

## Directory layout

```
cases/<CASE_ID>/
  README.md          physics, reference, discretization, and what this case does NOT show
  reference.json     reference value + citation + tolerance   ← COMMITTED BEFORE FIRST SOLVE
  run.sh             one command, reproduces everything from scratch
  *.i                MOOSE input(s); mesh sweep via CLI overrides, not copy-pasted files
  verify.py          reads MOOSE output, computes error, writes result.json + figure
  out/               raw MOOSE output (csv, exodus) — gitignored above 10 MB
  result.json        the verdict
```

`CASE_ID` is `T<tier>-<nn>_<slug>`, e.g. `T1-05_elastoplastic_cylinder`. It never changes once
created — it is the join key into the results table.

Mesh sweeps use command-line overrides so there is exactly one input file:

```bash
$MOOSE_APP -i case.i Mesh/nx=20 Outputs/file_base=out/n20
```

## `reference.json`

Written and committed **before** the first successful solve.

```json
{
  "case_id": "T1-05_elastoplastic_cylinder",
  "capability": "Elastoplasticity (J2 / von Mises)",
  "checklist_item": "1.1",
  "validation_class": "A",
  "quantity": {
    "name": "internal pressure at full plastic collapse",
    "symbol": "p_lim",
    "units": "MPa"
  },
  "reference": {
    "value": 80.4719,
    "uncertainty": null,
    "kind": "closed_form",
    "source": "Hill (1950), Mathematical Theory of Plasticity, §5.1: p_lim = sigma_y*ln(b/a) for Tresca, plane strain, incompressible fully-plastic thick cylinder",
    "derivation": "derivations/thick_cylinder.md",
    "confirmed_from": "derived symbolically in verify.py with sympy; cross-checked against Chakrabarty Eq. 3.14"
  },
  "tolerance": {
    "metric": "relative",
    "value": 0.02,
    "rationale": "von Mises vs Tresca differ by 2/sqrt(3) in the shear limit; 2% covers the mesh error, not the yield-criterion difference, which is handled by using the von Mises closed form"
  },
  "convergence": {
    "expected_order": 2.0,
    "refinement_levels": 3
  }
}
```

`kind` ∈ `closed_form` | `mms` | `numerical_benchmark` | `experiment` | `code_to_code`.
`validation_class` ∈ `A` | `B` | `E` — must be consistent with `kind`.

## `result.json`

Written by `verify.py`. One per case.

```json
{
  "case_id": "T1-05_elastoplastic_cylinder",
  "capability": "Elastoplasticity (J2 / von Mises)",
  "validation_class": "A",
  "reference_value": 80.4719,
  "moose_value": 80.9312,
  "units": "MPa",
  "error": { "absolute": 0.4593, "relative": 0.00571 },
  "tolerance": { "metric": "relative", "value": 0.02 },
  "convergence": {
    "levels": [
      {"h": 0.0100, "dofs": 2562,  "value": 82.104, "error": 0.02029},
      {"h": 0.0050, "dofs": 10082, "value": 81.318, "error": 0.01052},
      {"h": 0.0025, "dofs": 40002, "value": 80.931, "error": 0.00571}
    ],
    "observed_order": 1.93,
    "expected_order": 2.0
  },
  "verdict": "PASS",
  "runtime_s": 47.3,
  "ranks": 4,
  "moose_version": "snapshot-20-10-27-41583-g2bd11a08a7",
  "date": "2026-08-05",
  "notes": "Observed order 1.93 rather than 2.0 because the elastic-plastic front is not mesh-aligned; refining to h=0.00125 gives 1.97.",
  "limitations": "Plane strain, perfectly plastic, small strain, no hardening. Does not demonstrate kinematic hardening or ratcheting."
}
```

`verdict` ∈ `PASS` | `FAIL` | `PARTIAL` | `BLOCKED`.

- **PASS** — inside the pre-declared tolerance, and (for [A]) the observed order is within 0.2 of
  expected.
- **PARTIAL** — the physics runs and is checked against *something*, but the reference is weaker than
  planned (couldn't obtain the paper, benchmark mesh infeasible, only a qualitative law confirmed).
  `notes` must say exactly what is weaker. PARTIAL is a legitimate, honest outcome.
- **FAIL** — outside tolerance after the Rule 7 checklist. `notes` carries the diagnosis.
- **BLOCKED** — could not be built with input-file objects, or timeboxed out. `notes` carries what
  was tried.

Multi-quantity cases (e.g. Ghia compares a whole velocity profile) use `moose_value: null` and add:

```json
"profile": {
  "metric": "L2 norm of (moose - reference) over 17 Ghia sample points, normalized by U_lid",
  "value": 0.0083,
  "points": [{"y": 0.9766, "ref": 0.84123, "moose": 0.84019}, "..."]
}
```

The `metric` string must be specific enough that someone else computes the same number.

## Suite outputs

- `data/summary.csv` — one row per case, generated by `run_all.py`, never hand-edited.
  Columns: `case_id, capability, checklist_item, validation_class, reference_value, moose_value,
  units, rel_error, tolerance, observed_order, verdict, runtime_s`
- `RESULTS.md` — the human-readable capability table, generated from `summary.csv`. **This is the
  project's headline artifact.** Grouped by checklist section, verdict-colored, with the
  `validation_class` legend visible so nobody mistakes an [A] for an [E].
