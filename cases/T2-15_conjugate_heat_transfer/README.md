# T2-15 — Conjugate heat transfer

The case now builds a steady 2-D parallel-plate channel from a generated mesh: stabilized INS momentum and energy advection occupy the central fluid block, while separate conducting wall temperatures are coupled through explicit `ConjugateHeatTransfer` interface kernels. A parabolic inlet profile drives the flow and equal outer-wall heat fluxes provide the thermal load.

The planned reference is `Nu=8.235` for fully developed laminar parallel plates with both walls at constant heat flux. Matching parabolic inlet and outlet profiles enforce a developed-flow surrogate, and the fluid-wall interface conductance is set to `1e6` so the interface temperature jump is negligible. The verifier estimates a downstream Nusselt number from the velocity-weighted bulk temperature and interface wall temperature on 8×32, 16×64, and 32×128 meshes; the finest split-field estimate is `Nu=8.201` (0.41% error). Exact AD side-flux postprocessors confirm the imposed outer-wall flux is 1.0 per unit axial length. The full-interface mismatch (27.6%) is dominated by the inlet corner; an independent one-sided Exodus-gradient audit over `y>1` gives 3.83% fluid/wall mismatch, while each side agrees with the integrated finite-HTC transfer to 0.90% and 2.96%. The case remains PARTIAL because strict equal-gradient continuity is still not demonstrated.
