# T3-23 — Irradiation swelling eigenstrain

The open modules do not contain a BISON irradiation-swelling/creep law. This case therefore
isolates the input-level eigenstrain consequence with a declared linear correlation
`epsilon_v = 0.01*dpa`. The uniform-dose hand check is exactly zero differential stress; a
linear dose gradient produces a mismatch strain proportional to the gradient.

The correlation is an unverified placeholder because the cited journal source is not present.
This is not an experimental validation claim. It does not demonstrate irradiation creep,
void nucleation, dose-rate effects, or a source-backed material law.
